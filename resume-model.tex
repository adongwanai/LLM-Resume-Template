\begin{abstract}
福建农林大学人工智能专业硕士研究生在读，预计2027年6月毕业。研究方向涵盖深度学习、计算机视觉、时序信号分析及硬件感知人工智能。系统学习并实践了CNN、LSTM、Transformer、Vision Transformer及Swin Transformer等主流深度学习架构，具备从网络结构设计、张量流动分析到模型训练优化的完整理解能力。

科研方面，以第一作者开展基于忆阻器的仿生自修复神经网络研究，针对永久故障场景提出基于Gradient Mask的容错训练机制，在30\%器件故障率下恢复90\%以上模型性能；同时负责基于忆阻器的CHB-MIT数据集的癫痫发作预测研究，实现95.6\%的F1 Score。具备独立完成数据处理、模型设计、实验分析及论文撰写的能力。
\end{abstract}

\sectionTitle{科研经历}{\faAtom}
%======================================================================
\begin{itemize}
    \item \textbf{基于Gradient-Masked Training的仿生自修复忆阻器神经网络研究（第一作者）} \hfill 2024.10 --- 至今
    \begin{itemize}
        \item \textbf{问题背景：}忆阻器计算在边缘智能场景具备高能效优势，但器件永久故障会导致神经网络推理性能显著下降，严重影响系统可靠性。
        \item \textbf{研究内容：}受生物神经系统损伤后补偿性可塑性机制启发，提出基于Gradient Mask的自修复训练框架，通过冻结故障权重梯度并重新分配健康连接的表征能力，实现神经网络功能恢复。
        \item 基于忆阻器神经网络仿真平台完成故障注入实验，系统研究不同故障率下模型性能退化规律及恢复机制。
        \item 从分布式表征角度分析神经网络冗余特性，验证健康神经元对失效连接的功能补偿能力。
        \item \textbf{相关成果：}在30\%永久故障率条件下实现90\%以上模型性能恢复，目前论文正在整理投稿阶段。
    \end{itemize}

    \item \textbf{基于深度学习的癫痫发作预测研究（第一作者）} \hfill 2024.03 --- 至今
    \begin{itemize}
        \item \textbf{问题背景：}癫痫发作前脑电信号存在复杂时序特征，原始EEG数据类别极度不平衡，且短时间窗口难以充分捕获上下文信息。
        \item 基于忆阻器的CHB-MIT数据集构建完整脑电分析流程，实现EDF信号解析、多通道预处理及样本标准化。
        \item 设计2秒滑动窗口与50\%重叠采样策略，在增强样本数量的同时保留时间连续性。
        \item 针对类别不平衡问题引入Focal Loss，提升模型对少数类样本的关注能力。
        \item 结合窗口平滑机制增强时间上下文建模能力，提高预测结果稳定性。
        \item \textbf{相关成果：}模型F1 Score达到95.6\%，验证了所设计训练策略的有效性。
    \end{itemize}
\end{itemize}

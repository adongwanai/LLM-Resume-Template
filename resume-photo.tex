\begin{itemize}
  \item \textbf{项目背景}: 面向学术科研场景的 Agentic RAG 系统，支持 PDF 结构化解析入库、多路并行检索与自反思问答，具备多轮对话记忆、多模态图表理解及完整评估体系。
  \item \textbf{构建基于 LangGraph 的多 Agent 问答架构}: 主图采用 \texttt{classify $\rightarrow$ analyze $\rightarrow$ [sub\_agents $\times$ N] $\rightarrow$ synthesize} 流程；针对复杂多跳问题通过 Send 机制并行派发子查询，每个子 Agent 内执行 \texttt{retrieve $\rightarrow$ generate $\rightarrow$ reflect $\rightarrow$ retry} 的 ReAct 循环，最终聚合子答案并重映射引用编号；对话历史超过 6 轮时触发 LLM 摘要压缩，状态通过 AsyncPostgresSaver 持久化至 PostgreSQL 支持跨会话恢复。
  \item \textbf{设计混合检索与两阶段重排序管道}: 在 Milvus 中同时构建 Dense（bge-small-en）与 BM25 稀疏索引，通过 RRF 融合双路召回；引入 CrossEncoder（bge-reranker-v2-m3）对 Top-40 候选进行精排取 Top-5，相比纯向量召回 MRR 从 0.61 提升至 0.79；设计父子双集合分块策略（Child chunk 500字符/50重叠），检索命中 Child 后回溯 Parent 获取完整上下文，解决精准性与语义完整性的矛盾。
  \item \textbf{实现结构化 PDF 解析与多模态图表理解}: 采用 Docling 识别六类节点（段落/表格/图片/公式等），文字量不足时自动触发 OCR 降级；工厂模式节点生成器对表格线性化、对图片拼合 caption；集成 Qwen-VL 实现按需视觉分析，支持主动触发（查询含视觉关键词）与被动触发（reflect 判断答案不足时 fallback）双路径，单次最多处理 2 张图片控制推理成本。
  \item \textbf{构建双层评估体系并完成工程化部署}: 检索层使用自建测试集计算 Recall@k / MRR / MAP，生成层集成 RAGAS 评估 Faithfulness、AnswerRelevancy、ContextPrecision 四项指标，端到端输出 CSV 报告；后端基于 FastAPI SSE 实现逐 token 流式推送，前端 React 18 + ReadableStream 解析事件流；采用 Docker Compose 四服务编排（FastAPI + Nginx + Milvus + PostgreSQL），Makefile 封装开发命令。
\end{itemize}
